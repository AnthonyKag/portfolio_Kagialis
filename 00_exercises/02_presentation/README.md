# Markup Languages and Reproducible Programming in Statistics

Deliverables for *Markup Languages and Reproducible Programming in Statistics (202000010)*.

This repository was created to fulfil the course requirements for *Markup Languages and Reproducible Programming in Statistics* at Utrecht University. It follows the same license as the central course repository: [https://github.com/mlarpis/markup](https://github.com/mlarpis/markup)

The project focused on creating a reproducible Quarto presentation based on Exercise 2: [https://mlarpis.github.io/markup/week%202.html](https://mlarpis.github.io/markup/week%202.html)

The presentation is about my cat, Freud, and was designed to demonstrate the main technical features required by the assignment.

## Main files

The main files in this project are:

- `Course_presentation_Antonios Kagialis.qmd`
- `Course_presentation_Antonios Kagialis.html`
- `references.bib`
- `renv.lock`
- `Freud_Kagialis.png`
- `Freud_in_action.mp4`
- `freud_logo.jpeg`

The `.qmd` file contains the source code for the presentation, while an `.html` file is the rendered Reveal.js presentation (and it can be generated using the files provided here).

The `references.bib` file contains the bibliographic reference used in the presentation.

The `renv.lock` file records the R package versions used in the project and can be used to restore the computational environment.

The image and video files are used as visual and multimedia elements in the presentation.

## Main Software and packages used
The main software and packages used in this project include:
- R 4.6.1
- Quarto
- Reveal.js
- DT 0.34.0
- renv
