This is an enhanced implementation of the coding pipeline of the study published by Boulesteix et al. (2020) as part of an exercise for the course of Markup Languages and Reproducible Programming in Statistics. The complete instructions of the exercise along with the associated data can be accessed here:https://mlarpis.github.io/markup/week%204.html. The data come from the 2015-2016 National Health and Nutrition Examination Surey (NHANES).





**The project contains 5 main folders:**

\-The data folder that includes the datasets

\-The docs folder which includes the coding pipeline

\-The renv folder to facilitate reproducible coding environments

\-The results folder which contains the resulted figures

\-The scripts folder which contains additional helper functions.



**Disclaimer:** Portions of the text, comments and the code that appear in the pipeline has been generated/improved using ChatGPT under the direct supervision and instruction of the author. All AI generated contents have been individually reviewed.
