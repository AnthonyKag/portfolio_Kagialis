## Reproducible penguin manuscript

This research compendium was created for the [Quarto course exercise](https://mlarpis.github.io/quarto/) using R version 4.6.1.

### Folder structure

- `data/` contains the penguin dataset (`data.csv`).
- `docs/` contains the Quarto manuscript, bibliography, APA citation style, and rendered documents.
- `docs/images/` contains the penguin illustration.
- `scripts/` contains the R scripts used in the exercise.
- `renv.lock` records the R package versions used in the project.
