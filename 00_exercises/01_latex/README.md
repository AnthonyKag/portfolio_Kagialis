## Markup languages and reproducible programming in statistics

Deliverables for *Markup Languages and Reproducible Programming in Statistics (202000010)*.

This repository was created to fulfil the course requirements for *Markup Languages and Reproducible Programming in Statistics* at Utrecht University. It follows the same license as the central course repository: https://github.com/mlarpis/markup

The exercise focused on becoming familiar with the properties and use of LaTeX. More specifically, 01_latex folder contains my solution to Exercise 1.6: https://mlarpis.github.io/markup/week%201.html

## Main documents

The main outputs of the exercise are:

* `LaTeX_Peter.tex`
* `LaTeX_Clara.tex`
* `LaTeXdiff.tex`

All documents were created and compiled using Overleaf: https://www.overleaf.com

`LaTeX_Peter.tex` and `LaTeX_Clara.tex` answer the same exercise questions. The main difference between them is the external text file included in the document: `LaTeX_Peter.tex` includes `Peter.txt`, whereas `LaTeX_Clara.tex` includes `Clara.txt`.

`LaTeXdiff.tex` shows the differences between the two LaTeX documents.

## Secondary files

The `.png` files used for the figures and the `.txt` files included in the LaTeX documents are also provided to support reproducibility.
